# SPA-VLA Experiment Preview

This independent project-page preview uses an OpenVLA-style academic structure
with a restrained visual language inspired by Physical Intelligence. The
original template under `../site/` is unchanged.

The task showcase is organized as a desktop 3-column by 2-row video wall. Each
column represents one difficulty level (hard, medium, or easy). The page also
contains two extended-data stability tests, a six-task grouped result chart,
the ablation figure, and two paired qualitative comparison slots. Expected
video filenames are listed in `assets/videos/README.txt`.

Run `./serve.ps1` and open
`http://127.0.0.1:8765/experiment-preview/`.

The site is static and can be deployed directly from this directory. Internal
MP4 files are ignored by Git by default; publish video assets only after the
release status is confirmed.
